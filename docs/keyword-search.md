# 歌名 / 歌手搜索

在顶部输入歌名、歌手或关键词后按 Enter，或点击「搜索」。结果弹窗按视频显示封面、标题、UP 主、时长和播放量，支持翻页。

- 单 P 视频：点击「播放」通过原有播放器播放；点击「加入歌单」打开目标歌单选择框。
- 多 P 视频：先展开分 P，选择要播放或收藏的歌曲，也可以将全部分 P 加入歌单。
- BV 号、B 站视频链接、收藏夹 ID 和合集链接继续用于直接导入。纯数字按收藏夹 ID 处理；数字歌名可加上歌手名再搜索。
- 搜索结果不会批量解析视频。仅在选中视频时读取它的分 P 和 CID，然后复用原有音轨获取逻辑。

## 网络与登录

插件没有登录前置检查，也不会读取或保存账号密码。搜索请求允许浏览器携带 B 站已有的 Cookie（可能是访客 Cookie，也可能是登录态），访问是否放行由 B 站决定。沿用已有的域名权限，没有新增浏览器权限。

搜索先匿名读取 `/x/web-interface/nav` 中的公开 `wbi_img` 签名材料（接口即使返回 `code=-101` 仍可提供该字段），再按 B 站公开网页客户端的算法附加 WBI 签名，请求 `/x/web-interface/wbi/search/type`。MD5 使用固定版本的 `@noble/hashes`。

请求最长等待 15 秒，关闭弹窗时取消搜索；切换搜索或页码时忽略旧响应。HTTP 403 / 412 / 429、接口拒绝、验证票据和 HTML 验证页会显示提示。接口返回 `code=0` 但只有 `v_voucher` 时，也按需要验证处理，不会展示为「无结果」。

用户可点击「在 B 站打开搜索」自行检查网页并处理页面要求的验证，再回来重试。插件不会自动登录、完成验证码或循环重试。网页搜索可用并不保证扩展发出的接口请求一定可用。

## 验证

新增的回归用例覆盖关键词入口、响应归一化、风控错误、超时与取消、翻页失败重试、单 P 播放 / 收藏、多 P 选择以及关闭弹窗后的旧响应处理，位于：

- `tests/search.component.test.tsx`
- `tests/video-search.test.ts`
- `tests/video-search-dialog.test.tsx`

实际浏览器验收需要覆盖：歌名搜索、歌手搜索、第二页结果、无结果、单 P 播放 / 收藏、多 P 选曲，以及被 B 站限制请求后的提示与重试。匿名搜索应在未登录的浏览器环境单独验证。

安装开发版时，在 Chrome 扩展管理页开启开发者模式，加载构建生成的 `dist/` 目录。商店版与开发版的本地存储不会自动共用；需要迁移歌单时可使用原有的导出 / 导入功能。
